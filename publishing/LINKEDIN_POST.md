Sharing a personal software project: FINDEX — File Intelligence & Examination.

I built this Windows desktop utility to bring three file-examination tasks into
one application:

• Hash calculation and integrity verification
• Folder inventories with Excel and HTML reports
• Metadata examination with ExifTool and selectable report formats

FINDEX uses Python and PySide6 and works locally without an application login or
cloud account. I am sharing the source under the MIT license for learning,
feedback and collaboration.

This announcement is for the source-code project. A public installer release is
not included while native component distribution checks remain open. It is not
presented as a certified forensic tool.
