# FINDEX 3.0.1 — source publication

File Intelligence & Examination · Know Every File.

This publication shares the original FINDEX source and assets under MIT, with
separate third-party notices. It contains no Setup EXE, portable binary package,
ExifTool/ffprobe executable, Qt DLLs, case evidence or generated examination reports.

Existing Hash Verification, File Inventory and Metadata Explorer behavior is
preserved. See CHANGELOG.md for the current branding/report/export corrections.

The 2026-11-22 correction keeps Excel export working with an incompatible optional
NumPy installation and adds persistent Automatic/KB/MB inventory report sizes.
See FINAL_RELEASE_VERIFICATION.md for completed checks and filesystem-dependent
skips. No claim of forensic certification or absence of vulnerabilities is made.
Native Qt advisory findings and the separate bundled-binary distribution
limits are documented in NATIVE_DISTRIBUTION_REVIEW.md and SECURITY.md.

Please evaluate with synthetic files and share redacted reproduction steps.
Use INSTALL.md to run from source; local packaging is documented in BUILD.md.
