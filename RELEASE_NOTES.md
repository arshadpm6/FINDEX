# FINDEX 3.0.1 — Windows core preview

Download Setup or the portable ZIP from
https://github.com/arshadpm6/FINDEX/releases/tag/v3.0.1-core.

- Standalone core installation: Python and desktop/report dependencies included.
- Hash verification, inventories, Excel and HTML report generation.
- Existing NumPy-compatibility correction and Automatic/KB/MB report sizes retained.
- ExifTool and ffprobe are separate optional tools; follow README setup instructions.
- Unused Qt Network, QML/Quick, PDF and Virtual Keyboard components excluded.
- SHA-256 checksums, file inventories, dependency source archives and verification record included.

The installer is unsigned and this is a preview release. Read CORE_RELEASE.md,
SECURITY.md and VERIFICATION.md for the exact scope and validation limits.
